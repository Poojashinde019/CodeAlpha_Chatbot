Basic Chatbot 🤖

Project Description

This is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users and provides predefined responses based on their messages.

Features

- Greets the user.
- Responds to "Hello".
- Answers "How are you".
- Exits when the user types "bye".
- Handles unknown messages.

Technologies Used

- Python
- Functions
- While Loop
- If-Else Statements
- User Input
- String Methods

How to Run

1. Download the project.
2. Open the project in VS Code.
3. Run the following command:

python chatbot.py
